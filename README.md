# Lunox — Video & Audio Downloader

A portable Windows GUI downloader for YouTube and hundreds of other sites, powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [FFmpeg](https://ffmpeg.org/).

## Requirements

- Windows 10 / 11 (64-bit)
- Internet connection

## Installation

1. Download and extract the release archive.
2. Make sure `Lunox.exe`, `yt-dlp.exe`, and `ffmpeg.exe` are all in the **same folder**.
3. Run `Lunox.exe`.

## Usage

1. Paste a video/playlist URL into the box.
2. Pick a format, quality, and any extra options.
3. Click download. Finished files are saved into the `downloads` subfolder next to the app.
